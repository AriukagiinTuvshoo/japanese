# E2E шалгалтууд (B8)

Браузерын бүтээгдэхүүний түвшний шалгалт: офлайн, шинэчлэлт, эвдэрсэн
localStorage, зочин→аккаунт нэгтгэл, импорт/Undo. Node-ийн жинхэнэ скриптүүд
(`@playwright/test`-ийн тэсэлгээний тэмдэглэгч биш) — **фикс sleep 0**, бүх
хүлээлт нөхцөлөөр (`poll`).

## Ажиллуулах

```bash
npm ci
npm run test:e2e          # build (VITE_API_URL шигтгэсэн) + 5 сценарий
E2E_SKIP_BUILD=1 npm run test:e2e   # аль хэдийн баригдсан dist дээр (ажлын үе)
```

| Сценарий | Юу шалгана вэ |
|---|---|
| `01-offline.mjs` | Онлайн → SW кэшилнэ → **preview серверийг устгана** → home/vocab/kanji/grammar/review офлайнаар ачаалагдаж, фонт бүрэн, 0 console алдаа |
| `02-update.mjs` | Шинэ SW ирэхэд "Шинэ хувилбар бэлэн боллоо" toast → "Шинэчлэх" → шинэ SW идэвхжиж, хуучин `nd-*` кэшүүд устдаг |
| `03-corrupt-storage.mjs` | `nd:doc:local` эвдэрхий бол recovery мэдэгдэл + өөрийн түлхүүрт нөөц, **цагаан дэлгэц үгүй**, давтан ачаалалт хэвийн |
| `04-guest-merge.mjs` | Зочин ахицтай бүртгүүлэхэд "нэгтгэх" санал (default) гарч, XP аккаунтад шилжинэ, зочны хуулбар үлдэнэ |
| `05-import-undo.mjs` | Экспорт → өөрчилж импорт → **preview** (xp тоотой) → "Нэгтгэх" → нэг товшилт **Undo** буцаана |

Портууд: mock API `8791`, preview `4399` (`E2E_API_PORT` / `E2E_PREVIEW_PORT`
өөрчилж болно). **`VITE_API_URL` build-д шигтгэх нь чухал** — production
build API-г `apiBase() === null` учраас огт дууддаггүй; үгүйгээр "сервер
бэлэн" төлөвөөр нэвтрэх товч идэвхижихгүй.

## Rootгүй ажиллуулах (локал)

- Браузер: **системийн Chrome** ашиглана (`channel: "chrome"`) — суулгах,
  `sudo` шаардлагагүй.
- Chrome байхгүй бол татсан Chromium-оос унана: `npx playwright install chromium`
  (**`--with-deps` хэрэггүй** — түүнийг зөвхөн Linux дээр системийн номын
  сан (`apt`) суулгадаг бөгөөд тэдгээр аль хэдийн байгаа MacBook/Windows/
  Linux дээр шаардлагагүй. Уг шалгалт системийн Chrome-гүй Linux дээр
  ажиллахыг хүсвэл `npx playwright install-deps`-ийг локал админ эрхээр
  нэг удаа гүйцэтгэнэ үү).
- Ямар ч `sudo`/`apt` шаардлагагүй: скриптүүд системийн Chrome-г сонгоод,
  байхгүй бол татсан Chromium ашиглана.

## Танилтгүй хязгаарлалт (мэдээлэл)

- **`page.setOffline(true)` энэ апп дээр хангалтгүй.** Chromium-ийн offline
  нь SW-ээр дамжсан нэхэлтүүдийг бүрэн тасладаггүй (модуль скриптийг
  `cache-first` хэвээр авах боломжтой) → "интернэт тасарсан" мэдрэмж хуурамч
  байна. Тиймээс **серверийг үнэхээр устгаж** (01) офлайныг давшгүй болгоно.
- Нэг сценарийг нэг процесс болгон шилжүүлсэн нь изолаци (шинэ браузер
  профайл, 0 портын мөргөлдөөн), гэхдээ бүх сценарийн дараа нэг дор
  `npm run test:e2e` ажиллавал нийт хугацаа 2–4 мин.
- Мок API нь жинхэнэ `server/` биш: тэр байхгүй (Phase 5); зориуд
  `GET /api/sync → rev 0` буцаана → клиент merge-ийг санаатайгаар
  асаахгүй (эхний таталтад).
