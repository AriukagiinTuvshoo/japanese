төлөвлөгөө юм. Зорилго нь шинэ боломж зохиох бус, **дутууг нөхөх** — давхардсан
функц нэмэхгүй.

- Огноо: 2026-11-01
- Суурь commit: Phase 1B (`phase-1b` ажлын дараах HEAD)
- Хамрах хүрээ: Phase 2–7 (Phase 1A = SRS + storage, Phase 1B = статистик +
  өгөгдлийн бүрэн бүтэн байдал + smoke E2E — дууссан)

## Ерөнхий дүрэм (бүх phase-д)

1. Нэг Phase = нэг milestone. Phase дунд шинэ функц нэмэхгүй.
2. Милстоун бүр: unit тест + `data:validate` + `test:smoke` ногоон байж дуусна.
3. UI-д demo өгөгдөл ашиглахгүй — бүх асуулт бодит сангаас (`src/lib/study.ts` дүрэм).
4. Монгол орчуулга баталгаажаагүй бол `mq: "draft"` хэвээр; `curated` болгохын тулд
   хүний хяналт шаардна (validator `vocabMnCurated` тоог шалгадаг).
5. Хэрэглэгчийн өгөгдлийг (`nd:doc:*`) хөндөх migration зөвхөн `storage.ts`-ээр,
   нөөц хуулбартайгаар.
6. Шинэ боломж бүр SRS/статистиктай холбогдоно — тусдаа тоолуур үүсгэхгүй
   (`stats.ts` нэг эх сурвалж).

  бол өсөх эрсдэлтэй.
