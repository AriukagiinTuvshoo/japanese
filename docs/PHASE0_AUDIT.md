## 3. СУРАХ ЛОГИК — кодын алдаа (file:line)

### P0-1. SRS: алдсан карт хэдэн өдрийн дараа буцаж ирдэг
`src/lib/srs.ts:109` нь Again үнэлгээнд `due = now + 10 min` гэж тавина. Тэгээд
`src/lib/srs.ts:119-123`:

```ts
// Fuzz: нэг өдөрт хэт олон карт хуримтлагдахаас сэргийлнэ (±5%)
if (c.st > 3) {
  const fuzz = 1 + (Math.random() - 0.5) * 0.1;
  c.due = now + Math.max(1, Math.round(c.st * fuzz)) * DAY;
}
```

Төлөвшсөн карт (st=20) алдвал `st → 7` болж, **fuzz нь 10 минутын интервалыг ~7 хоногоор
дарж бичнэ**. Өөрөөр хэлбэл хамгийн их мартсан карт хамгийн удаан буцаж ирнэ — SRS-ийн
үндсэн зорилгын эсрэг. Fuzz нь зөвхөн `g > 0` салбарт байх ёстой.

Нэмээд: `newCard`-ын Good (2) нь комментын "эхэндээ 4 өдөр"-ийн оронд **1 өдөр** буцаана
(`st=1.4` → `round(1.4)=1`), learning step (1м/10м) байхгүй.

### P0-2. Холимог/сул дасгал асуултын тоог 1/5 болгож хасдаг
`src/lib/study.ts:284-319`:

```ts
const per = Math.max(1, Math.ceil(count / realModes.length));  // 15 / 6 = 3
for (const m of realModes) { ... if (out.length >= per) break; ... }
```

`out.length` нь **нийт** асуулт боловч `per`-тэй харьцуулж байна → эхний горим 3 асуулт
үүсгэмэгц бүх давталт зогсоно. **Хэмжсэн:** `#/quiz` дээр 15 асуулт хүсэхэд
`Холимог N5 3 асуулт`, сесс `1 / 3`. `mixed`, `weak`, мөн `buildExam`-ийн хэсэг бүр
(`study.ts:433`) ижил алдаатай.

### P0-3. Төлөвийн баримт бичиг schema-гүй → апп унана
`src/lib/store.tsx:159-172` `readDoc` нь зөвхөн `profile`, `srs`, `activity`-г "хэвийн" болгож,
бусад талбарыг шалгалгүй `...parsed`-аар дарж бичнэ. `v:3` хувилбарыг **хэзээ ч шалгахгүй**,
migration байхгүй. §2-ын цагаан дэлгэц үүнээс.

### P1-4. Олон төхөөрөмжийн синк = өгөгдөл алдах зам
`src/lib/store.tsx:340-375`: `push()` нь `doc`-оо ямар ч rev/updatedAt харьцуулалгүй
`PUT /api/sync` руу илгээнэ; `pull()` зөвхөн `remote.updatedAt > doc.updatedAt` үед дарж бичнэ.
Нэвтрэх дараалал нь `pull().then(() => push(true))` — **pull-ийн дараа шууд хуучин локал
doc-оо push хийнэ**. Хоёр төхөөрөмж зэрэг ажиллавал сүүлд push хийсэн нь нөгөөгийнхөө
ахицыг дарна. Merge/conflict resolution байхгүй (зөвхөн `rev` талбар).

### P1-5. Бичих алдаа чимээгүй алга болно
`src/lib/store.tsx:177-182`:

```ts
try { localStorage.setItem(...) } catch { /* санах ой дүүрсэн — туршилтын горимд алгасна */ }
```

Quota дүүрэх/private mode-д хэрэглэгч **юу ч мэдэхгүй**, ахиц нь хадгалагдахгүй. Мэдэгдэл,
retry, export санал байхгүй.

### P1-6. Бүртгүүлэхэд зочны ахиц хаягдана
`src/lib/store.tsx:545-552`: `signUp` → `switchUser(res.account.id, …)` → шинэ uid-ийн
`nd:doc:<id>` хоосон → `freshDoc()`. `nd:doc:local` дахь ахиц **шилжихгүй**, UI-д анхааруулга

### P1-7. Import нь буцаах боломжгүй
`src/lib/store.tsx:585-593`: `importJSON` нь JSON.parse-с ард шалгалтгүй `setDoc` → 350 ms-ийн

### P1-8. Жишиг шалгалтын "тэнцсэн" дүрэм өөрийнхөө тайлбартай зөрчилдөнө

### Тема
- `prefers-color-scheme: dark` идэвхтэй үед ч `body` = `rgb(247,242,232)` / `rgb(28,27,24)` —
  **харанхуй горим байхгүй**. `Profile.theme: "light" | "sepia"` тодорхойлогдсон боловч
  **хаана ч хэрэгжихгүй** (`Account` хуудсанд ч хяналт байхгүй).
- `theme-color` meta нэг л (#1c1b18), `media`-гүй.

### Гар утас 360 px
- Ерөнхийдөө **хэвтээ скроллгүй** (scrollWidth = 360) ✅
- `#/write/日` дээр **+2 px** overflow (`button.flex shrink-0` → 466 px).
