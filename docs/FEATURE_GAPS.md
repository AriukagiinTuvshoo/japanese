## 3. СОНСГОЛ (Listening)

### 3.1 Өгөгдлийн схем (`ListeningLesson`)

```jsonc
{
  "id": "n5-l01", "title": "Дэлгүүрт", "titleJp": "店で",
  "channel": "…", "youtubeId": "…",        // одоогийн схем: YouTube гадаргуу
  "level": "N5", "topic": "shopping", "minutes": 3,
  "status": "approved",                     // зөвхөн approved нь нийтэд харагдана
  "transcript": [{ "ja": "これはいくらですか。", "mn": "Энэ хэд вэ?", "at": 12.4 }],
  "vocab": [{ "w": "いくら", "r": "いくら", "mn": "хэд" }],
  "questions": [{ "q": "…", "opts": ["…","…"], "a": 1, "why": "…" }],
  "shadowing": ["これはいくらですか。"]       // давтан ярианы дасгал
}
```

### 3.2 Аудио стратеги (3 шатлал)

1. **Web Speech API (`speechSynthesis`, `lang="ja-JP")` — default, бүрэн офлайн ажиллана.**
   - Бэлэн: `src/components/ui.tsx` → `speak()` (дууны хурд `profile.rate` дэмжинэ).
   - **Graceful fallback (заавал):** япон хэлний дуу байхгүй бол (`getVoices()` дээр `ja` үгүй) →
     автомат дуулгалыг **хааж**, ишлэл/транскриптийг тэмдэглэгээтэй харуулна + урьдчилсан
     мэдэгдэл: *"Энэ төхөөрөмж дээр япон дуу байхгүй — текстийг уншина уу."*
     Дуу **хоосон/алдаатай** бол сэргийлнэ (ажиллахгүй байхыг орлуулахгүй).
   - Тэмдэг: Chrome/Edge/Safari дээр япон дуу ихэвчлэн байдаг; Firefox/төхөөрөмжийн
     тохирол хамааралтай → заавал тестлэх (доор "Нээхээс өмнөх acceptance").
2. **Урьдчилан үйлдвэрлэсэн аудио (suoas — сонголт, N5→N4-ээс эхлэх).**
   - Формат: **MP3/OGG 32–64 kbps**, 12–40 секунд, `public/audio/<id>.mp3`, нийт **< 25 MB** (PWA precache-аас бусад, background cache).
   - Эх: (a) өөрийн TTS-ээр (bosh) **эсвэл** (b) япон дүрмийн дуун бичлэг (Fiverr/сургалт) — эцсийн дүнд **хэрэглэгчид өгөх эрхийг** баталгаажуулах.
   - Дууны эрх: эхийн **эзэн/зөвшөөрөл** (`status: "approved"`) — одоогын YouTube model хэвээр.
3. **YouTube embed** — одоогийн `ListeningDetail` ажилладаг ч **офлайн ажиллахгүй**; шинэ
   контентод эхний 2 шатлалыг илүүд үзнэ.

### 3.3 Хэрэгтэй зүйл (доод хэмжээ)

| Түвшин | Багадаа | Аудио |
|---|---|---|
| N5 | **20** хичээл (2–3 мин) | TTS, өгүүлбэр түвшин |
| N4 | **20** хичээл | TTS + богино яриа |
| N3 | **24** хичээл | ярианы ток / мэдээ богино |
| N2 | **24** хичээл | ярилцлага, мэдээ хэсэг |
| N1 | **24** хичээл | хурдан яриа, илтгэл хэсэг |
| **Нийт** | **112 хичээл** | бүрэн транскрипт (MN орчуулга) + 4–6 асуулт + shadowing |

Нэг хичээл бэлтгэх: **~3–4 цаг** (контент + транскрипт + орчуулга + асуулт + аудио шалгалт) →
**~340–450 цаг (42–56 ажлын өдөр)**. Аудио үйлдвэрлэл нэмэлт **~1 цаг/10 клип**.
